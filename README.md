# KWNet

This repository contains the official implementation of KWNet, a deep learning framework for breast histopathological image classification.

The code is associated with the manuscript currently under submission:

**KWNet: A Reliability-Aware Multi-Stage Evidence Network for Breast Histopathological Image Classification**

## Overview

KWNet is designed for breast histopathological image classification. 

This repository will provide the implementation needed to reproduce the main experiments reported in the manuscript.

## Repository Status

The manuscript is currently under submission. The source code will be released upon publication.

At this stage, only the repository structure and basic project information are provided.

## Dataset

The experiments are conducted on the BreakHis dataset.

Dataset link: https://www.kaggle.com/datasets/ambarish/breakhis

Please download the dataset from the official source and follow its usage terms. The dataset is not redistributed in this repository.
